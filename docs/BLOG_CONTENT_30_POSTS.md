# Lading - Blog Posts and Cover Prompts (paired with the 30 social videos)

For each of the 30 social videos in `docs/SOCIAL_CONTENT_30_POSTS.md`, this file gives:
1. A paste-ready blog post (title, slug, description, tags, body) for the admin blog editor at `/admin/blog`.
2. A cover image generation prompt (16:9).

How to use:
- Admin -> Blog -> New post. Paste the title, slug, description, tags and body.
- Paste the video links from the matching social post (YouTube, TikTok, Instagram, Facebook, Threads, Bluesky).
- Generate the cover with the prompt (Midjourney, Ideogram, DALL-E, Firefly, etc.), upload it in the Cover section.
- If you skip the cover, the blog automatically uses the YouTube thumbnail when a YouTube URL is present.

Cover prompt style guide (applies to all):
Premium fintech-logistics aesthetic. Brand palette: Deep Harbor #0B1F33, Signal Teal #0E9F8E, Manifest Amber #F2A93B, Cloud #F5F7FA. Clean, calm, engineered, lots of negative space, soft studio light, shallow depth of field, 16:9, 1200x630, no text in the image. Avoid: globes, handshakes, swooshes, node webs, stock-photo models, gradients, 3D, clutter.
